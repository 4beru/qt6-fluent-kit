# Contributing to Qt6 Fluent Kit

Qt6 Fluent Kit is maintained through its public project channels.

## Before opening an issue

- Search existing Issues and Discussions first.
- For reproducible bugs, include the Qt/Qt6 Fluent Kit version, operating system, architecture, installation route, and a minimal reproduction.
- For feature ideas, describe the user outcome and the reusable problem being solved.
- Remove credentials, customer data, private repository links, and local paths from reports.

## Where to contribute

- [Bug reports](https://github.com/4beru/qt6-fluent-kit/issues)
- [Discussions](https://github.com/4beru/qt6-fluent-kit/discussions)
- [Support](SUPPORT.md)
- [Security policy](SECURITY.md)

Changes to the implementation are maintained in the project's private source repository. Public Issues and Discussions are the appropriate channels for user-facing feedback, documentation problems, release issues, and reproducible behavior.

Please read the [Code of Conduct](CODE_OF_CONDUCT.md) before participating.
